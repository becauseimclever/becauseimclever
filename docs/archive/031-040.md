# Feature Archive: 031-040

> Archived summaries of completed and cancelled features. Original documents preserved for reference.

## Features

### 031 - Fluent UI CSS Variable Cleanup
**Status:** Completed  
**Summary:** Removed residual Fluent UI variable usage from client styling and aligned affected components with the project theme system based on `--color-*` variables. Updated `ExtensionWarningBanner`, `ConsentBanner`, `DataDeletionForm`, and `PrivacyPolicy` styles, with additional consent modal polish and CSS isolation linkage.  
**Key decisions:** Standardized on project CSS variables instead of legacy Fluent UI tokens; kept warning intent while making banner visuals theme-aware; preserved responsive behavior on mobile.

### 032 - Scheduled Post Visibility and Published Date Fix
**Status:** Completed  
**Summary:** Fixed public visibility so only `Published` posts are returned from public listing queries, preventing `Scheduled`/`Draft`/`Debug` content from appearing early. Updated status transitions so `PublishedDate` is reset when publishing, including scheduler-driven publication flow.  
**Key decisions:** Applied status filtering at query level in `DatabaseBlogService`; kept direct slug lookup permissive for preview use cases; set `PublishedDate` during publish transitions in `AdminPostService` with scheduled-date handling when applicable.

### 033 - Code Coverage to 90% Across All Projects
**Status:** Completed  
**Summary:** Completed backend coverage hardening and reporting alignment so the enforced CI threshold is measured against the intended backend-only surface. Verified results now show 96.1% line / 87.5% branch in the CI-style enforcement-aligned view and 98.8% line / 88.0% branch in the strict backend-only view, with test execution at 933 passed and 0 failed.  
**Key decisions:** Enforced a backend-only threshold at 90%+ line coverage; excluded Blazor UI, startup wiring, and generated code from the active gate; kept Blazor UI coverage visible but non-blocking; aligned the published GitHub coverage summary with the same enforcement scope to prevent reporting drift; retained regression protection so backend coverage drops below threshold fail the build.

### 034 - Post Editor Spell Checker
**Status:** Cancelled (2026-10-31)
**Summary:** The owner chose separate writing/editing tools and browser-native spell checking instead of a custom checker. PR #26 was closed without merging; no custom implementation is present in the application.
**Key decisions:** Preserve the editor's `spellcheck="true"` and existing test; cancel custom overlays, dictionary APIs/assets, preferences, and future checker enhancements. [Original proposal and cancellation](034-post-editor-spell-checker.md).

### 035 - Japanese Character Support
**Status:** Cancelled (2026-10-31)
**Summary:** The owner has no current plans to write Japanese posts; dedicated Japanese fonts and typography work are premature.
**Key decisions:** Cancel the proposed enhancement without changing existing Unicode handling or browser font fallbacks. No feature-specific implementation was found. [Original proposal and cancellation](035-japanese-character-support.md).

### 037 - Clock Page Timezone Selection
**Status:** Completed  
**Summary:** Added a timezone selector to the Clock page, defaulting to the local timezone and updating the clock display and timezone label when changed.  
**Key decisions:** Uses client-side `TimeZoneInfo` conversion without persistence or a server API. [Original feature document](037-clock-timezone-selection.md).

### 038 - Release Process Revamp
**Status:** Completed (confirmed 2026-10-31)
**Summary:** Implemented CI, native amd64/arm64 image publication, MinVer version calculation, prebuilt images, and automated changelog/releases. Verified successful v1.1.1 publication and deployment.
**Key decisions:** Keep existing separate CI/image/release triggers and simple deployment; CI configuration is authoritative for coverage policy. [Completed feature document](038-release-process-revamp.md).

### 039 - Copilot Customization Reorganization

**Summary:** Reorganized repository Copilot guidance into concise root instructions, focused instruction files, and a reusable feature-document workflow skill.

### 040 - Blazor UI Accessibility Agent
